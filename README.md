# Naomi's EventFest

## Description
Naomi's EventFest is your go-to platform for discovering and registering for unforgettable events. Whether you're interested in concerts, corporate events, or weddings, this web app provides an easy way to explore upcoming events and register your interest for the ones that excite you the most.

The site includes a registration form to allow users to express their interest in different event types and keep up-to-date with upcoming events, making it a convenient hub for event lovers.

## Features
- **User Registration**: Users can submit their interest for various events such as concerts, corporate events, and weddings.
- **Upcoming Events Display**: A gallery showcasing events users can explore.
- **Event Registration Form**: A simple form for users to sign up for their preferred event types.
  
## Behavior-Driven Development (BDD)
- **Given** a user is on the EventFest site
- **When** they view the upcoming events section
- **Then** they can register for the events by submitting their details in the form
